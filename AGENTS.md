# dsh-lab

- Feature documentation lives in `docs/features/`. Read the relevant feature document before changing a feature.
- The repository has one workspace bundle package, `packages/lab-sidebar`, for the LabSideBar product.
- The bundle inserts two independent rows: `lab-sidebar` (sidebar host, client, and icon route) and `lab-tools` (the `workspace` and `session` agent tools). Disabling the `lab-tools` row removes the tools without touching the sidebar.
- TypeScript sources live under `packages/lab-sidebar/src/`. The emitted `index.js`, `tools.js`, and `client.js` are generated by `scripts/build-*.mjs`; do not edit them by hand.
- Commands: `npm run typecheck`, `npm run bundle`, `npm test`.
- The current DSH profile links this package. A rebuilt host module needs a plugin manager change or window reload before it is live.
